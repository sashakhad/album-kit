# Examples from mus1c for v3gans

Two track sheets from [mus1c for v3gans](https://music-for-vegans.vercel.app/listen/mus1c-for-v3gans), each with the synthesis note from its prompt arena. They're copies of the working files, with Suno song IDs removed.

- [`PHOTOSYNTHESUPERSIZEME.md`](PHOTOSYNTHESUPERSIZEME.md): a new song from a Blank Create. It has five prompts in five different lanes for one title, the Suno settings, the take filenames, and the joke kept out of every Style paragraph. The track was renamed Fot0synthesupersiz3me later, and the sheet's first lines show it.
- [`PHOTOSYNTHESUPERSIZEME-SYNTHESIS.md`](PHOTOSYNTHESUPERSIZEME-SYNTHESIS.md): how its arena went. It covers the job the track does on the album, the scores from the picker and the cross-judge, the source of each final prompt, and every rejected lane with the reason.
- [`S0Y-MAR1ACHI.md`](S0Y-MAR1ACHI.md): a track extracted from another track's take. Every prompt is a Cover of that one take, changing one thing at a time. It also shows how the letters were remapped when the takes moved, and where the judging stood.
- [`S0Y-MAR1ACHI-SYNTHESIS.md`](S0Y-MAR1ACHI-SYNTHESIS.md): an arena aimed at a failure the judging found. The hook came back too often and the floor arrived too late, so each new prompt fixes that a different way.

These sheets predate the kit, so they don't match its sheet format exactly. The first lists its files instead of a table, and the second's table has a Pass column where the kit has Prompt. Read them for the thinking, and use `album-track` for the format.
